End-to-End Execution Flow
Excel Data Import:
 Admin or Lead uploads an Excel sheet. The frontend dynamically parses header columns regardless of column ordering and posts student objects to the backend. 
Dynamic Role Views (RBAC):
 Users log in as ADMIN, MANAGER, LEAD, or STUDENT. The UI toggles layout dashboards based on the logged-in role. 
Company Status Pipeline:
 Placement leads add companies (COLD 
→
 WARM 
→
 HOT 
→
 DRIVE_COMPLETED). Updates trigger admin approval notifications if created by a lead. 
Automated ATS Scoring:
 When matching candidates against a Job Description, Spring Boot extracts the Google Drive file ID, fetches resume text, and queries gemini-2.5-flash in JSON Mode to output an ATS score (0–100) and category mapping. 
Report & Export Generation:
 Filtered student profiles and drive-completed company stats are rendered into data grids with direct CSV export support.
